# Fonts

`inter.c` is generated by `bake.py` (`rake ui:fonts`) from Inter SemiBold. Don't edit it by hand.

- Font: Inter 4.1 by Rasmus Andersson and the Inter Project Authors, https://rsms.me/inter/
- Release: https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip (SHA-256 `9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e`)
- File: `extras/ttf/Inter-SemiBold.ttf` in that archive (SHA-256 `78a843fade9d4612a5567302fb595b56976eb5fcebf4fea5a5912d638bafcde3`). `brew install --cask font-inter` installs it where `rake ui:fonts` looks by default; `INTER_TTF=path` points it elsewhere.
- Licence: SIL Open Font License 1.1, copied from the release as [OFL-Inter.txt](OFL-Inter.txt). The baked bitmaps are a modified version of the font under that licence.
- Sizes: 20, 36 and 80 px, 4-bit alpha, printable ASCII (the 80 px only the characters of channel names), with Inter's tabular digits.

## Icons

`icons.c` and `icons.h` are generated by `bake.py icons` (also `rake ui:fonts`) from Font Awesome Free. Don't edit them by hand.

- Icons: Font Awesome Free 7.3.1 by Fonticons, Inc., https://fontawesome.com/
- Release: https://github.com/FortAwesome/Font-Awesome/releases/download/7.3.1/fontawesome-free-7.3.1-desktop.zip (SHA-256 `c61edde261707f33376a28e9a30bb8c70c1a20bf0bd975206b809f3b3b70add5`)
- Files: `otfs/Font Awesome 7 Free-Solid-900.otf` (SHA-256 `daa92774861a14e9ccbccc5e73a5fba514271ba4d1bd7e5adbf952182bc00835`) and, for the USB logo, `otfs/Font Awesome 7 Brands-Regular-400.otf` (SHA-256 `6232968ccac5ea8ef40ec03da2961b94e791c629451d358e82f96c49fb318799`). Names map to code points through the release's `metadata/icons.json`. `brew install --cask font-fontawesome` installs the release where `rake ui:fonts` looks by default; `FONTAWESOME_DIR=path` points it at another copy of the unzipped release.
- Licence: the icons are under CC BY 4.0 and the font files under the SIL Open Font License 1.1, both in [LICENSE-FontAwesome.txt](LICENSE-FontAwesome.txt), copied from the release. CC BY asks for credit, which this section gives.
- Icons: usb, desktop, slash, hand-pointer, circle, sd-card, bars, table-cells and grip, at 24 and 36 px. Each sits centred in a cell as wide as the set's widest icon, so slash drawn at hand-pointer's origin lands where Font Awesome's layering puts it.
