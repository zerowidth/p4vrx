# firmware/p4

ESP-IDF firmware for the ESP32-P4 on the Waveshare 4.3" touch board: console and
protocol, C5 control and esptool bridge, FPGA control over I2C, bus capture,
display and touch UI, UVC, H.264, DVR.

Written fresh, porting pieces from `../../reference/p4usb`. Name the reference
file in the commit message of each port, and give ported files a
`SPDX-License-Identifier: GPL-3.0-only` header.
